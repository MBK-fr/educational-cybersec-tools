# Security Policy

## Reporting a Vulnerability

If you find a security issue with any tool listed in this repository, or if you find a link that points to malicious content:

1. **Do NOT open a public issue**
2. Email the details to the repository owner
3. We'll investigate and act within 48 hours

## Responsible Disclosure

This repository links to third-party security tools. If you discover vulnerabilities in any of those tools, follow the respective project's responsible disclosure policy.

## Scope

This policy covers:
- Malicious or misleading links in this repository
- Insecure content in submitted PRs
- Issues with the repository structure itself

This policy does NOT cover:
- Vulnerabilities in the tools we link to (report those to the tool authors)
- GitHub platform security (report to GitHub directly)
