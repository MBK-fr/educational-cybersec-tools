# Contributing to Educational Cybersecurity Tools 🛡️

First off, thanks for wanting to contribute. This is a community-driven resource and every addition helps.

## How to Contribute

### Adding a New Tool
1. Fork the repo
2. Find the right category in the README
3. Add your tool in the format: `| **Tool Name** | Brief description | [github.com/...](URL) |`
4. Test your link works
5. Submit a PR with a clear description

### Adding a New Category
If you think a whole new category is needed:
1. Open an issue first to discuss
2. Explain why the category is needed
3. Include at least 5 tools that would go in it
4. We'll integrate it

### PR Guidelines
- Keep descriptions concise (one line)
- Link to official repos, not mirrors or forks
- No affiliate links or paid tools (free/open-source preferred)
- Include the tool's primary function

### Issues
- Bug reports (broken links, incorrect info)
- Feature requests (new categories, improvements)
- Questions about tools or techniques

## Style Guide
- Use proper Markdown
- Keep the table format consistent
- Alphabetical order within categories where possible

## Recognition
All contributors get a shout-out in the README. Good contributions get merged fast.

---

**Remember**: This is for education. Don't submit malware, doxing tools, or anything illegal.
